About

A compact, presence-only MaxEnt workflow used in the ModLand project. The template assumes a study area, a presence table, and any number of GeoTIFF predictors. Outputs include a suitability raster and a quick-map preview.

How to reuse

Keep rasters aligned (CRS, resolution, extent). Document the EPSG in the YAML before running.
  1. Place study_area.shp (+ sidecars) and presence.csv in /data.
  2. Add GeoTIFFs to /data/rasters (any number, any names).
  3. Adjust YAML parameters (EPSG, background size, output names) and knit the Rmd locally.
  4. Find outputs in /outputs (suitability raster and quick map).
