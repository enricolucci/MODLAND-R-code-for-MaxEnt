About

A compact, presence-only MaxEnt workflow used in the ModLand project. Provide a study area, presence table, and GeoTIFF predictors; the script returns a suitability raster and a quick map.

How to reuse

  1. Place study_area.shp (+ sidecars) and presence.csv in /data.
  2. Add GeoTIFFs to /data/rasters.
  3. Adjust YAML parameters (EPSG, background size, output names) and knit locally.
  4. Outputs saved to /outputs (suitability raster and quick map).

Tip: keep rasters aligned (CRS, resolution, extent) and document the EPSG in the YAML to avoid resampling artefacts.
